1.Erklären Sie den Unterschied zwischen der Line con und der Line vty.

*  Line con (Console Line): Repräsentiert den physischen Konsolen-Anschluss (RJ45/RS232/USB) am Router oder Switch. 
Sie wird für den lokalen Direktzugriff per Konsolenkabel verwendet – insbesondere bei der Erstkonfiguration oder wenn das Netzwerk nicht erreichbar ist.


* Line vty (Virtual Terminal Line): Repräsentiert virtuelle Terminal-Sitzungen für den Fernzugriff über das Netzwerk (z. B. via Telnet oder SSH). 
Ein Gerät verfügt typischerweise über mehrere VTY-Lines (z. B. line vty 0 4 für 5 parallele Verbindungen).

R1(config)# ip ssh version 2

! Lokalen Benutzer anlegen & Enable-Secret setzen
R1(config)# username admin privilege 15 secret Admin***123!
R1(config)# enable secret ***123!

! VTY-Lines auf SSH umstellen
R1(config)# line vty 0 4
R1(config-line)# login local
R1(config-line)# transport input ssh
R1(config-line)# exit

6.Worin liegt der Unterschied zwischen SSH und Telnet?

Eigenschaft				Telnet	                      				 SSH (Secure Shell)

*Verschlüsselung		   Keine (Klartext)	  			Starke Verschlüsselung (Asymmetrisch/Symmetrisch)

*Sicherheit			Unsicher (Passwörter & Daten abfangbar)	  	   Sicher gegen Eavesdropping & Man-in-the-Middle

*Port				    TCP Port 23			  			TCP Port 22 

*Authentifizierung	     Einfaches Passwort oder unverschlüsselt 		Passwort, RSA/ECDSA-Keys, Zertifikate


*Einsatzbereich		      Nur in isolierten Laborumgebungen				Standard für Produktion und Fernwartung
